# MF Алматы / Lanttich

MF Алматы / Lanttich — B2B интернет-магазин мебельной фурнитуры для клиентов, которым нужен удобный каталог, быстрый подбор позиций и оформление заказов в одном интерфейсе.

Проект объединяет публичную витрину, клиентский кабинет и административные инструменты для управления ассортиментом.

## Возможности

- Каталог мебельной фурнитуры с категориями, фильтрами и поиском.
- Карточки товаров с изображениями, характеристиками, чертежами и B2B-действиями.
- Корзина и оформление заказов с сохранением истории покупок.
- Профиль клиента с контактными и доставочными данными.
- Административная панель для работы с товарами, категориями, заказами, прайсами и интеграциями.
- Поддержка персональных условий для B2B-клиентов.

## Технологии

- React и Vite для клиентского интерфейса.
- FastAPI для серверной части.
- PostgreSQL для хранения данных.
- SQLAlchemy и Pydantic для работы с моделями и схемами данных.
- JWT-авторизация и разграничение доступа по ролям.
- Контейнерная инфраструктура для развёртывания.

## Назначение

Система разработана для мебельного B2B-сегмента: она помогает клиентам быстрее находить нужную фурнитуру, собирать заказ и работать с поставщиком через единый цифровой канал.
